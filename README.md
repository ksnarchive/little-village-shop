# 🌿 Little Village Shop

A cozy pixel-art shop management game made with **Godot 4** and **GDScript**.

> 🚧 Work in progress — first prototype. The project has not yet been tested in the Godot editor.

## The idea

Run a small countryside shop: order goods, restock shelves, serve customers and grow a welcoming neighborhood store.

## Current prototype (Stage 1)

- A small shop room with wooden shelves, storage, counter and ordering desk
- A shopkeeper character rendered with simple procedural pixel shapes
- Keyboard movement and collisions with walls and furniture
- Godot project settings for a 640×360 pixel-art viewport

## Run

1. Install Godot 4.x (desktop editor).
2. Download or clone this repository.
3. Open `project.godot` in Godot.
4. Press **F5** to run the main scene.
5. Use **WASD** or **arrow keys** to move.

The game is currently desktop-oriented; a browser export may be added later.
