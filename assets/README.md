# Оригинальная графика: осенняя винтажная лавка

Интерьер магазина продолжает художественное направление сюжетного поезда:
насыщенные ореховые и янтарные тона, кремовая бумага, хвойный зелёный, бордо,
потёртые материалы и объёмный свет. Оригинальные растровые мастера созданы
с помощью image generation специально для проекта, без сторонних наборов.
Они находятся в `art/shop/` и исключены из импорта/экспорта через `art/.gdignore`.
Pillow используется только для подготовки небольших игровых PNG:

```sh
python3 tools/prepare_shop_art.py
```

`scenes/art/shop_interior.tscn` собирает комнату из отдельных текстур пола,
обоев, штукатурки, деревянных панелей, окон, шкафов, бытового декора, пыли и
световых пластин. Полки, сундук, стол заказов и касса остаются независимыми
интерактивными объектами. Декор стоит за прежними границами прохода. Товары
появляются на пустых полках только из настоящего инвентаря.

Товары и базовые UI-значки сохранены из предыдущего этапа. Актуальный конвейер
персонажей описан ниже.
`tools/build_shop_art.py` — **исторический** генератор старой комнаты и этих
ресурсов; его запуск перезапишет новую мебель. Для текущего интерьера используйте
только `prepare_shop_art.py`, который не трогает персонажей и товары.

В архивном атласе: хозяйка в оливковом фартуке, гость в соломенной шляпе, седая гостья с
косичками, гость в оливковой кепке. Точка привязки (12,20), физика непрерывная;
округляется только отрисовка. Фильтрация nearest, mipmaps выключены.

Комната приближена камерой в 1,15 раза. Правая витрина поднята на 16 пикселей;
маршруты покупателей берут её подход из самой сцены. Остальные коллизии, проходы,
очередь и дверной проём сохранены. Декор боковых стен стоит за существующими
границами прохода и не создаёт новых интерактивных объектов.

## Шрифт

`fonts/PixelifySans.ttf` — исходный Pixelify Sans, © 2021 The Pixelify Sans Project
Authors, [проект](https://github.com/eifetx/Pixelify-Sans), SIL OFL 1.1
([лицензия](fonts/OFL.txt)). `VillagePixel-Regular.ttf` — статическая производная
начертания 400 под новым именем Village Pixel: добавлена отсутствовавшая заглавная
**П**, заглавная **О** использует латинскую O. Все 66 русских букв проверяются тестом;
системная подстановка шрифтов отключена. В игре используется производная.
Для воспроизведения нужен fonttools:

```sh
python3 tools/build_shop_font.py
```

Текущие реальные скриншоты и протокол проверки:
[`docs/illustrated-shop.md`](../docs/illustrated-shop.md).
Предыдущий этап: [`docs/autumn-vintage.md`](../docs/autumn-vintage.md).

## Игровые персонажи и гардеробная

Оригинальные художественные мастера в `art/characters/` созданы с помощью image
generation с персонажем поезда как ориентиром. Восемь причёсок и шесть нарядов
имеют фронтальный, задний и левый виды; правый получается зеркальным отражением.
Кожа, радужки и волосы выделены в независимые нейтральные материалы. Все прежние
ID и палитры `CharacterAppearance` сохранены; каждый вариант доступен всем.

```sh
python3 tools/prepare_character_art.py
```

Ячейка — 64×96, игровой прямоугольник — 28×42 с прежним положением стоп.
Направления down / up / left / right. Одежда и руки имеют восемь поз на вид:
покой, покой при моргании, шесть фаз ходьбы. Головы, лицо и радужки используют
только две позы на вид, волосы — три положения кончиков. Рендерер согласует
покачивание головы с шагом тела, не дублируя портрет для каждого кадра ног.
Слои покупателей `npc_heads.png` / `npc_clothes.png` используют ту же сетку,
масштаб и цикл. Их три безымянных варианта различаются лицом, возрастом и одеждой.

`frontend/dressing_room.png` — новая гардеробная с пустым стеклом; отражение
героя рисуется тем же `CharacterArt`, что герой на ковре и в магазине.
`wardrobe_ambient.png` — небольшой спокойный фон полей редактора. Мастера
исключены из импорта и экспорта через `art/.gdignore`; в игре нет Pillow,
генерации пикселей или новых шейдеров. [Проверка и реальные кадры](../docs/character-art-direction.md).

`frontend/{village,cloud,leaves}.png` остаются из предыдущего этапа. Их старый
генератор `tools/build_frontend_art.py` также перезаписывает гардеробную и
персонажей: не запускайте его для текущих ресурсов. Текущий источник подготовки
персонажей — только `prepare_character_art.py`.

## Поезд: иллюстрация и слои внешности

Новые оригинальные пиксельные иллюстрации и атласы созданы для проекта с помощью
image generation по художественному заданию; изображения пользователя служили
референсами материалов, света и композиции, а не исходниками для копирования.
Редактируемые растровые мастера находятся в `art/train/` и исключены из импорта
и веб-сборки через `art/.gdignore`.

`tools/build_train_art.py` готовит две композиции, прозрачные оконные проёмы,
трёхкадровые шторы, световые пластины, пар и бесшовные панорамы. Палитра каждой
основной пластины ограничена 256 цветами, фильтрация nearest. Полные мастера не
загружаются во время игры. `tools/build_train_actor.py` выделяет независимые
цветовые материалы кожи, волос и радужки; эти материалы окрашиваются значениями
существующего `CharacterAppearance`. Восемь причёсок и шесть нарядов сохраняют
прежние ID и доступны всем персонажам.

```sh
python3 tools/build_train_art.py
python3 tools/build_train_actor.py
```

Готовые PNG включены в репозиторий; Python и Pillow нужны только для подготовки
ресурсов. Звук `train/rails.wav` — прежний оригинальный PCM-цикл колёс из PR #14,
22 050 Гц, 6 секунд; художественная доработка его не меняет.

[Описание оформления и реальные скриншоты](../docs/train-art-direction.md).
