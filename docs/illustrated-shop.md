# Старая лавка в золотом осеннем свете

Художественная доработка от актуальной `main` (`6248662`, включая исправления
iOS из PR #15). Прочитаны `GAME_DESIGN.md` и `train-art-direction.md`.
В разделе 1 геймдизайна закреплены три уровня детализации: сюжетная иллюстрация,
игровая локация и портрет. Оформление поезда стало общим направлением игры.

## Интерьер

Сохраняется прежняя камера сверху в три четверти и вся планировка. Старая лавка
получила тёплый дощатый пол с сучками и царапинами, потёртые цветочные обои,
осыпавшуюся штукатурку, тёмные деревянные панели, сколотые полки, сундук с
латунной фурнитурой, письменный стол и механическую кассу. У боковых стен стоят
шкафы, старые коробки, корзины и банки; видны радио, сухие травы и паутина.
За окнами — золотые осенние деревья. Мягкие оконные лучи и контактные тени
поддерживают объём, не затрудняя чтение товаров и проходов.

По сравнению с поездом плотность деталей намеренно ниже: крупные материалы
связывают интерьер с иллюстрацией, а свободный центр оставляет место движению
и покупателям. Увядшие обои, сколы и пыль показывают состояние до ремонта.
Интерфейс магазина использует кремовую бумагу, ореховые рамки, хвойные кнопки
и золотой фокус. Девятисегментная страница сохраняет прежний переплёт и стежки,
с отдельной перекрашенной копией текстуры. Прежние размеры, подписи, меню
и сенсорные действия сохранены.
Тема ограничена магазином; меню создания героя и поезд используют прежнюю тему.

## Ресурсы и повторное использование

Как для поезда, сначала созданы оригинальные художественные растровые мастера
с помощью image generation, затем подготовлены отдельные игровые PNG:

- `art/shop/materials.png` — дерево, обои, штукатурка, деревянные панели;
- `art/shop/furniture.png` — два пустых стеллажа, сундук, стол, касса и шкаф;
- `art/shop/decor.png` — окна, ковёр, бытовые предметы и повреждения стен.

`tools/prepare_shop_art.py` удаляет технический пурпурный фон атласов, выделяет
предметы, приводит к прежним размерам и ограничивает их палитры 192 цветами.
Материалы получают зеркальное продолжение без швов. Свет и пыль подготовлены
как отдельные прозрачные пластины; они не запечены в единственный фон комнаты.
Мастера исключены из Godot через `art/.gdignore` и не загружаются в игре.

`scenes/art/shop_interior.tscn` содержит 28 обычных Sprite2D без скриптов,
коллизий, частиц, анимационных циклов и новых источников света. Пол и стены
растягиваются region/repeat; окна, шкафы, ковры, декор и свет можно независимо
переставлять и переиспользовать. 16 модульных текстур занимают около 1,22 MiB
в RGBA до накладных расходов драйвера. Фильтрация nearest, без mipmaps.
Пять интерактивных спрайтов сохраняют прежние размеры, точки привязки и места
рисования реального товара. Вместимость полок остаётся 12, кладовой — 60.

Не менялись позиции объектов, камера, коллизии, подходы к полкам, очередь,
маршруты покупателей, экономика, сохранения, персонажи, NPC, редактор, поезд,
HTML shell, iOS viewport/клавиатура, экспорт и механизм кеширования релизов.
В `web/smoke.cjs` обновлён только ожидаемый цвет активной кнопки сохранения.
Новых механик и ремонта нет; архивный `room.png` сохранён, но не используется.

## Реальные кадры

Изображения ниже сняты с работающего Godot 4.3, без дорисовки или композитинга.
Для кадров с ассортиментом `tools/capture_illustrated_shop.gd` выполняет обычные
покупки и переносы через production API, ждёт трёх естественно пришедших
покупателей и открывает настоящее меню инвентаря. Время дня фиксируется для
сопоставимости. Этот необязательный инструмент не открывает слот сохранения
и исключён из релизного экспорта.

Мобильные кадры сняты `web/capture-shop-art.cjs` с настоящего release-экспорта
в WebKit: новая игра, создание героя, штатный пропуск поезда, поворот экрана
и открытие рюкзака обычными сенсорными нажатиями. Состояние игры не подменяется.

## Воспроизведение проверки

```sh
python3 tools/prepare_shop_art.py
GODOT_BIN=/path/to/godot-4.3 bash tests/run_checks.sh
godot --path . --audio-driver Dummy --script res://tools/capture_illustrated_shop.gd
godot --headless --path . --export-release Web builds/web/index.html
python3 tools/package_release.py builds/web "$(git rev-parse HEAD)" --ref refs/heads/art/illustrated-village-shop
python3 -m http.server 8060 --directory builds/web
cd web
npm test
BROWSERS=chromium npm run test:gameplay
npm run capture:shop-art
```

Физический iPhone недоступен. Мобильные проверки Chromium/WebKit с профилем
iPhone проверяют настоящий веб-экспорт, сенсорные действия и поворот viewport,
но не воспроизводят полностью Safari на устройстве, его панели, GPU и системную
клавиатуру. Они не доказывают частоту кадров на физическом телефоне.

Все **1014 существующих Godot-проверок** прошли без ошибок, включая торговлю,
вместимость и переносы, пути покупателей, кассу, сохранения, размеры меню,
редактор и поезд. В тесте персонажей остаётся прежнее предупреждение ObjectDB
при завершении процесса; SCRIPT ERROR/ERROR и проваленных проверок нет.

Однопоточный Web release Godot 4.3 экспортируется без ошибок и упаковывается
прежним `package_release.py`. Полный `npm test` прошёл: smoke и frontend в
Chromium/WebKit, полное вступление с возобновлением и переходом в магазин,
WebKit cache-upgrade с сохранением IndexedDB и WebKit iOS-keyboard/viewport.
Дополнительно **Chromium `--gameplay`** прошёл закупку, переносы, выкладку,
реальную продажу (баланс 102), ручное сохранение, Continue и поворот экрана
на окончательных ресурсах. Мобильная съёмка WebKit завершилась без ошибок.
