# Главное меню и создание персонажа

Ветка основана на `main` (`8db2c11`). Движок и экспорт: Godot **4.3 stable**.

«Новая игра» открывает отдельную сцену `scenes/character_creator.tscn`.
Если прогресс уже есть, меню сначала предупреждает о его замене. Возврат из
гардеробной ничего не записывает. Подтверждение сохраняет новый первый день
атомарно; ошибка записи оставляет прежний магазин, прежнее сохранение и открытый
редактор с сообщением. «Продолжить» восстанавливает существующий магазин.

Варианты доступны без выбора пола: 6 оттенков кожи, 8 причёсок, 8 цветов волос,
6 цветов глаз, 6 нарядов. Имя — от 1 до 24 символов. Пробелы по краям и управляющие
символы удаляются. «Случайно» меняет внешность, сохраняя введённое имя. Стрелки под
зеркалом поворачивают персонажа, «Походка» показывает обе фазы шага. Список вариантов
прокручивается мышью или пальцем, Tab переводит фокус и прокручивает список к нему.
Кнопки подтверждения и возврата остаются снаружи прокрутки.

`CharacterArt` собирает героя из пяти совмещённых пиксельных атласов: тело,
одежда, детали лица, глаза и волосы. Гардеробная, отражение и движущийся герой
магазина используют один и тот же рендерер для всех четырёх направлений.
Существующие жители и игровые механики магазина сохранены.

Сохранения версии 2 содержат `character` вместе с товарами, монетами, временем и
итогами дня. Версия 1 читается без изменения файла: имя «Саша» и стандартная
внешность применяются только в памяти. Следующее обычное сохранение записывает
версию 2. Неизвестные версии остаются защищены от автоматической подмены резервной
копией. Некорректные индексы внешности отклоняются до изменения состояния игры.

Настройки анимации фона и общей громкости записываются отдельно в
`user://village_settings.cfg`. В браузере файлы находятся в IndexedDB этого сайта.
В меню и гардеробной экранные кнопки магазина скрыты. В портретной ориентации
используется вертикальная компоновка; при входе в магазин возвращаются прежний
игровой viewport и экранное управление. Элементы редактора имеют высоту минимум
44 логических пикселя. Веб-экспорт включает экспериментальную виртуальную
клавиатуру Godot 4.3 для поля имени.

## Проверка и воспроизведение

```sh
GODOT_BIN=/path/to/godot-4.3 bash tests/run_checks.sh
mkdir -p builds/web
godot --headless --path . --export-release Web builds/web/index.html
python3 tools/package_release.py builds/web "$(git rev-parse HEAD)" --ref local
python3 -m http.server 8060 --directory builds/web
# В другом терминале:
cd web
npm ci
npx playwright install --with-deps chromium webkit
npm test
npm run test:gameplay
BROWSERS=chromium npm run capture:frontend
```

`frontend.cjs` управляет обычным интерфейсом реального release-экспорта: открывает
настройки, вводит русское имя, меняет внешность, включает поворот и походку,
поворачивает экран, подтверждает героя, перезагружает страницу, нажимает
«Продолжить» и снова сохраняет игру. Проверка читает реальный файл IndexedDB,
не подменяя игровое состояние. `smoke.cjs` продолжает проверять существующие
экранные кнопки, инвентарь, сохранение и игровой цикл.

## Результаты этой проверки

- Godot 4.3: **894 проверки, 0 ошибок**; импорт и стартовая сцена также прошли.
- Однопоточный Web release: сборка успешно выполнена официальными шаблонами 4.3.
- Chromium и WebKit: меню, настройки, русское имя, живая внешность, случайные
  варианты, поворот, походка, портретная компоновка, IndexedDB и «Продолжить» — PASS.
- Изображение нестандартного героя в магазине до и после «Продолжить» совпало
  попиксельно в обоих браузерных движках.
- Оба браузера: существующие экранные кнопки, меню, ручное сохранение и поворот
  экрана магазина — PASS.
- Chromium: полный цикл закупки → склад → рюкзак → полка → продажа → сохранение →
  «Продолжить» — PASS.
