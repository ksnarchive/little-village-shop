# Купе в золотом осеннем свете — художественная доработка PR #14

Доработка продолжает `feat/train-prologue` от `6a290a3`, а не начинает новую
реализацию от main. Прочитан `GAME_DESIGN.md`; пользовательское художественное
задание уточняет насыщенность палитры для вступительной иллюстрации.

## Что изменилось

Вместо симметричного фронтального вагона — диагональный вид изнутри купе.
Слева крупный столик с чашкой чая, газетой, ложкой и сухим кленовым листом;
справа — герой на мягком узорном сиденье, багаж и багажная полка. Большое окно
с золотыми шторами связывает планы. Глубину задают стол и бордовое сиденье
переднего плана, тёмные нижние поверхности, солнечный кант и резные панели.

Основные материалы опираются на тёмное дерево `#57312E`, орех `#94513A`, янтарь
`#D58B39`, золото `#F6D47D`, хвойный зелёный `#354E43`, бордо `#7E383B`,
небесный `#ADC8C4` и кремовый `#F3E4C5`. Винтажность передана фактурой дерева,
бархата, латуни, керамики и потёртой кожи, с выраженными светом и тенью.

Телефон получает отдельную вертикальную живописную композицию того же купе.
Это позволяет одновременно сохранить чашку, окно, сидящего героя и чемодан.
Широкая композиция используется на ПК и при горизонтальном повороте телефона.
В маленьком портретном viewport масштаб ограничен так, чтобы панель оставалась
над нижним ковром, а не поверх лица или чашки.

Герой рисуется полными сидячими слоями 96×144: головы/волосы для восьми причёсок,
шесть нарядов с согнутыми ногами и обувью, руки, отдельные радужки и закрытые
веки. Кожа, волосы и глаза окрашиваются по прежним сохранённым параметрам.
Портреты выровнены по радужке; исходные skin/hair/eye material-ID цвета не
попадают в готовое изображение. Наряды сохраняют отличия фартука, кардигана,
комбинезона, полосатого свитера, сарафана и рубашки с платком.

## Спокойные анимации и производительность

Существующее движение панорамы и торможение сохранены. Новые панорамные слои
содержат цельные естественные кроны, хвойные леса, поля и небольшие домики.
Зеркальное продолжение каждой полосы делает повтор непрерывным.

Пар — готовый 12-кадровый атлас. Шторы — три заранее подготовленных растровых
кадра со смещением складок на один исходный пиксель. Дыхание меняет высоту
спрайта менее чем на пиксель при неподвижных подошвах; моргание использует
независимые веки. Световая пластина мягко смещается, а тень близкого дерева
периодически затеняет иллюстрацию и героя, не затрагивая текст. При отключённых
анимациях все фазы и расстояния остаются неизменными. Кадровых генераторов
деревьев, пиксельных циклов, частиц, физических симуляций и новых шейдеров нет.

В игре используются подготовленные PNG, основные пластины с палитрой 256 цветов
и nearest-фильтрацией. Полноразмерные художественные мастера в `art/train/`
исключены из импорта и экспорта через `.gdignore`. Это оригинальные ресурсы,
созданные с помощью image generation для проекта; три присланных референса
использованы как художественное направление. Мастера и оба скрипта подготовки
ресурсов включены в PR для дальнейшего редактирования.

## Интерфейс и сохранность функциональности

Панель стала ниже: полупрозрачный тёмный фон, кремовый текст, золотые акценты и
одна сенсорная кнопка в правом нижнем углу. Подсказка о способе нажатия убрана.
«Вид» / H скрывает UI, а касание возвращает его без продвижения текста.

`train_story.gd`, `save_store.gd`, миграции, стартовое меню, переход в магазин,
торговля, настройки звука, WAV, HTML shell, package_release и release guard не
менялись. Ошибки записи по-прежнему показываются и допускают повтор действия.
Добавленное скрытие панели не меняет checkpoint и не создаёт отдельный режим
прохождения. Станция, игровая деревня и свинка не добавлены.

## Воспроизведение

```sh
python3 tools/build_train_art.py
python3 tools/build_train_actor.py
GODOT_BIN=/path/to/godot-4.3 bash tests/run_checks.sh
mkdir -p builds/web
godot --headless --path . --export-release Web builds/web/index.html
python3 tools/package_release.py builds/web "$(git rev-parse HEAD)" --ref refs/heads/feat/train-prologue
python3 -m http.server 8060 --directory builds/web
cd web
npm test
npm run capture:train-art
```

Физический iPhone в окружении недоступен: мобильные сценарии проверяются
Chromium/WebKit с профилем iPhone. Проверка реального Safari остаётся полезной
для платформенных особенностей звука и системных safe area.

Проверка ветки: **1013 Godot-проверок, 0 failures**, в том числе 119 проверок
поезда, сохранений, старых версий, отказов записи, сенсорных событий и размеров
всех полных абзацев. Дополнительно проверены отдельные слои всех восьми причёсок,
шести нарядов, моргание и возврат из просмотра иллюстрации без изменения прогресса.

Полный `npm test` завершён успешно: Chromium и WebKit прошли существующие
smoke/frontend-сценарии и полную поездку с возобновлением, поворотом экрана,
пропуском и возвратом в лавку. WebKit cache-upgrade также прошёл: версии
HTML/JS/WASM/PCK, IndexedDB и отказ запуска при недоступном манифесте проверены.
Однопоточный Web release Godot 4.3 экспортируется штатным механизмом без ошибок.
