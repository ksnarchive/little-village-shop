# Вступление: поездка на поезде

Реализация этапа 1 из [GAME_DESIGN.md](GAME_DESIGN.md), Godot 4.3. После подтверждения имени и внешности новая игра открывает `scenes/train_intro.tscn`. После поездки временно открывается существующая игровая лавка; станция, деревня и следующие сюжетные этапы не добавлены.

## Сцена и управление

Художественная часть переработана поверх первой реализации PR #14: теперь это
асимметричное купе в перспективе три четверти, с отдельной вертикальной
композицией для телефона. Объёмные деревянные поверхности, золотистые занавески,
зелёная узорная обивка, чай, газета и старый чемодан создают планы иллюстрации.
Герой справа смотрит в окно; полный сидячий спрайт имеет собственные слои для всех
выбранных параметров внешности. Исходные параметры персонажа не меняются.

Панорама за окном сохраняет многослойный параллакс. Пар над чашкой, движение
складок, дыхание, моргание, световые пятна и тени проезжающих деревьев добавлены
только в визуальный слой. Отключение анимаций фиксирует все эти эффекты. Прежний
звук и общая громкость сохранены.

Текст и порядок реплик не изменены. Десять мыслей, объявление, торможение на
3,5 секунды и затемнение на 1,2 секунды работают как прежде.

- Касание / щелчок по сцене или диалогу, Enter, Пробел, E: сначала раскрыть печатающуюся реплику, затем перейти к следующей.
- «Пропустить…» / Esc: прежнее подтверждение пропуска с безопасным фокусом.
- «Вид» / H: временно скрыть весь UI. Касание возвращает текст, не переключая реплику и не записывая новый прогресс.
- Компактная тёмная полупрозрачная панель использует кремовый текст и золотистые акценты. Кнопки сохраняют высоту 44 логических пикселя; лишние подсказки на мобильном экране убраны.

Подробности ресурсов, ограничений и новые кадры: [train-art-direction.md](train-art-direction.md).

## Сохранения

Схема v3 добавляет `story: {train_line, train_complete}`. ID реплик фиксированы в `TrainStory`; при дальнейшем изменении последовательности нужна явная миграция.

Новая игра атомарно сохраняет персонажа, стартовый магазин и незавершённое вступление **до** выхода из редактора. Каждая следующая реплика сохраняется тем же проверенным механизмом временного файла, резервной копии и rename. При ошибке записи возвращается прежняя контрольная точка, реплика остаётся на экране и предлагается повторить действие. Завершение/пропуск сохраняется **до** затемнения и включения магазина.

«Продолжить» для незаконченной поездки восстанавливает последнюю сохранённую реплику с начала её текста. Это продолжение прерванной новой игры, а не повтор уже завершённого вступления. Завершённые поездки больше не показываются. Сохранения v1/v2 считаются прошедшими вступление; v1 получает прежний стандартный облик, v2 сохраняет выбранного героя. Состояние денег, товаров и дня миграцией не меняется. Некорректные контрольные точки отклоняются до применения состояния; повреждённый основной файл восстанавливается из проверенной `.bak`.

Во время поездки весь магазин и его UI отключены: часы не идут, покупатели не появляются, экономика не изменяется. Веб-хранилище остаётся на прежнем origin и `/userfs`; запись в IndexedDB синхронизируется штатным механизмом Godot. При немедленном закрытии вкладки возможен возврат к последней уже синхронизированной реплике. При выходе из поездки персонаж и торговые данные не теряются.

## Проверки и реальные кадры

Команды:

```sh
GODOT_BIN=/path/to/godot-4.3 bash tests/run_checks.sh
mkdir -p builds/web
godot --headless --path . --export-release Web builds/web/index.html
python3 tools/package_release.py builds/web "$(git rev-parse HEAD)" --ref refs/heads/feat/train-prologue
python3 -m http.server 8060 --directory builds/web
cd web
npm ci
npx playwright install --with-deps chromium webkit
npm test
npm run capture:train
```

Godot-тесты покрывают торговые механики, старые сохранения, внешность, возобновление/завершение поездки, отказы записи, повреждённые контрольные точки, резервную копию, отсутствие фонового продвижения магазина, сенсорные события, отключение анимаций и размеры всех абзацев на четырёх пропорциях экрана.

Браузерные сценарии работают с настоящим release-экспортом, сенсорными/клавиатурными событиями и чтением фактического IndexedDB, без внедрения игрового состояния. Проверяются движение картинки, ручное переключение текста, перезагрузка в середине поездки, поворот экрана, подтверждение пропуска, объявление/затемнение, внешность и неизменность товаров/денег, отсутствие повтора после завершения. Существующие проверки торговли и кеширования сохранены; механизм версионирования HTML/JS/WASM/PCK, release guard и путь сохранений не изменены.

WebKit с профилем iPhone проверяет мобильный браузерный сценарий; физическое устройство iPhone/Safari в этом окружении недоступно. Ручная проверка на нём остаётся необходимой для особенностей системной клавиатуры, safe area и аудиополитики Safari.

Фактический результат проверки этой ветки:

- Godot **4.3.stable.official.77dcf97d8**: **1013 проверок, 0 ошибок**, включая 119 проверок поезда; импорт и стартовая сцена проходят.
- Single-threaded Web release успешно экспортирован и упакован штатным `package_release.py`.
- Chromium и WebKit: существующие smoke/frontend-сценарии и полное прохождение поезда — **PASS**.
- WebKit iPhone cache-upgrade: кешированный HTML, версии JS/WASM/PCK, Cancel/Continue, неизменность IndexedDB и отказ запуска при недоступном манифесте — **PASS**.
- Размеры всех полных реплик проверены при 640×360, 400×740, 400×660 и 740×400; браузерный поворот также проверен при 390×844, 667×375 и 844×300.

В быстрых headless save/character-тестах Godot 4.3 иногда печатает предупреждение
`ObjectDB instances leaked at exit` для `AudioStreamWAV/AudioStreamPlaybackWAV`:
процесс завершается сразу после освобождения сцены, до следующего прохода
аудиомикшера. Проверки завершаются с кодом 0; в полном прохождении поездки
и браузерных сценариях ошибок движка и JavaScript нет.
